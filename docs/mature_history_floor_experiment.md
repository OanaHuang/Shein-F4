# 第6轮固定实验设计：成熟历史承运商时长下限

2026-11-18，在第5轮结果及开发标签诊断后制定。本轮是开发阶段的新假设，两个开发窗口此前已被查看；不是未见数据上的确认性检验。

## 动机与唯一改动

LSP_0004的同批校准包裹中，可见标签Q97约322／329小时，最终签收后的Q97约517／511小时。后者只用于事后诊断，禁止直接作为当时预测的下限。原校准主要缺少当时尚未签收的慢件，换树模型未解决该问题。

固定一条历史统计规则，对所有承运商一致适用：在各窗口截止C之前已签收、且issue_time严格早于C减21天的官方训练记录中，计算每家承运商的max(Q90(y), Q97(y)-24小时)。每组至少200条，否则保留原预测。最终预测=max(原校准后预测, 历史统计值)。

21天为本次开发假设的固定观察年龄，不代表此时所有慢件已签收；不搜索其他天数、分位数、组门槛或融合权重，不按本轮评估分数修改。历史标签仍只使用sign_time<C，不能补入此次事后诊断中当时不可见的标签。

## 对照与信息边界

依次在dev_1、dev_2运行，各窗口对原LightGBM＋校准、承运商基线＋校准应用同一规则。复用已有预测，不重新训练树或原校准器；保留所有原结果与固定评估键。新增历史键单独记录，不改原fit/cal/eval键。

该改动增加了截至C可用的较老历史标签；它们可以与原模型训练记录重叠。因此这是历史统计后处理，不是新的独立残差校准。若有收益，应归因于新增历史信息及下限规则，不能宣称LightGBM结构本身改善。为公平判断，简单基线也获得完全相同的历史信息。

先冻结历史统计并生成预测，再读取开发评估标签评分。排除最终留后键，核对原预测、源数据、切分和评估键摘要；不使用任何最终留后标签。历史样本为空、键冲突或来源变化必须失败，不移动日期补救。

## 记录与判断

主指标为官方A，保留ME、两项罚分、平均承诺、逐包MAE、分组覆盖、被抬高预测比例和资源开销。不能只报A收益而省略承诺时长变长的代价。结果无论好坏都保留，暂不替换默认模型。

本次历史数据同样来自最终已签收的官方样本，不是完整到件人口；观察年龄筛选也不能消除所有未签收选择偏差。两个开发窗口重叠92,779条，不能视为独立确认。最终留后继续锁定。
