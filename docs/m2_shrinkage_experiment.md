# 原M2的校准改进实验

日期：2026-11-18。目的：在原LightGBM＋校准的基础上做一项可归因的改动，以官方A（越低越好）为主指标，同时报告平均承诺、MAE和分组覆盖。工程完善不作为效果提升证据。

## 固定对照与信息边界

对照是`local_dev1_20261118_01_calibrated`，原dev_1 A=421.534469。复用它已经拟合的LightGBM及类别编码器；不更改树、特征、训练样本或两个分位数，不重新训练主模型。

使用原dev_1的校准键与标签截止，拟合新的校准器；评估键、官方评分和最终留后隔离保持不变。数据、模型和编码器摘要不一致即失败。实验只测试下面这一条固定规则，不搜索系数、不根据评估分数挑参数。

## 改动及依据

原校准为每家承运商统一加一个偏移。它能修正整体水平，却完全保留LightGBM对同组包裹的时长差异。首轮公平对照中，承运商常数＋校准优于M2，说明这些包裹级差异未必可靠。

本实验用校准样本估计每家承运商的固定线性系数：

```text
slope = clip(cov(原模型预测, 实际时长) / var(原模型预测), 0, 1)
center = 校准样本中原模型预测的平均值
adjusted = (1 - slope) × center + slope × 原模型预测
delta = max(Q90(实际时长 - adjusted), Q97(实际时长 - adjusted) - 24)
最终承诺 = adjusted + delta
```

斜率为0时回退到承运商常数；为1时保留原模型的全部差异；中间值只保留部分差异。方差为0时斜率取0。组样本不足200或新承运商使用全局系数和全局残差校准。最小组样本数沿用原M2，不调参。

这里的斜率根据校准样本的线性关系拟合，不是直接优化官方A，不能保证提升。可见标签偏向快件的问题仍然存在；这个实验只针对模型差异不可靠的问题。
